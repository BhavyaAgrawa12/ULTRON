# Welcome

Welcome to **Project ULTRON**.

ULTRON is **not** a chatbot.

It is an **AI Operating Companion Platform** designed to become the
user's second brain by remembering, reasoning, acting, learning, and
connecting across devices.

Before writing code, read this document.

------------------------------------------------------------------------

# Vision

Build an intelligent operating companion that:

-   Remembers important context
-   Reasons about user intent
-   Acts safely on behalf of the user
-   Learns user preferences
-   Connects multiple trusted devices

------------------------------------------------------------------------

# Product Principles

1.  AI is the last option.
2.  Local-first architecture.
3.  Performance before features.
4.  Security by default.
5.  Modular architecture.
6.  User owns their data.

# Definition of Done

A task is complete only if:

-   Code works
-   Tests pass
-   Documentation updated
-   No performance regression
-   No architecture violations

------------------------------------------------------------------------

# AI Prompt Rules

When using AI coding assistants:

-   Never ask for the whole project.
-   Generate one module at a time.
-   Follow documented architecture.
-   Do not invent APIs.
-   Respect module boundaries.
